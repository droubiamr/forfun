# forfun

A playground of small, delightful things built with Claude, pushed as far as it can go.

Nothing here has to be useful. Each project should feel finished, have a point of view, and make someone smile when they open it.

## House rules

- **Ship it whole.** Something small that's done beats something big that's half-built. If it opens, it should feel good.
- **Light by default.** Plain HTML/CSS/JS wherever possible, no build step, no frameworks unless they earn their place. If it doesn't load instantly on a phone, it's too heavy.
- **Details are the point.** The little things (a flickering streetlamp, a cat on a wall, the right shade of sunset) are what make it worth building.
- **Real-world hooks welcome.** Live time, weather, and sky make a toy feel alive.
- **Free APIs only, no keys in the repo.**
- **Each project lives in its own folder**, with a `README.md` saying what it is and how to open it, and the `PROMPT.md` that started it.
